# State Laws Affecting Frontier US AI Companies

A single-page site mapping enacted US state legislation on frontier AI companies,
read against the California SB 53 baseline (the Transparency in Frontier AI Act):
for each provision axis, which state goes furthest, exactly how each state's law
differs from the template, and which asks no state has passed.

Built at the FAI "Hacking the Think Tank II" hackathon, 2026-07-31. **Status: scrappy
MVP.** Every statutory claim was verified against primary sources (statute text,
legislature records, court dockets) on 2026-07-31; the framing copy is interim and
will be rewritten.

## Data model

`data/states.json` is canonical: 51 state records, 9 provision categories, every
provision carrying a tag (copies SB 53 / falls short / goes beyond), a § cite, a
source URL, and a confidence level. `data/states.js` is generated by `prep.py`
(which also inlines the map SVG). Tests: `node --test test/*.test.js` and
`python3 test/validate_data.py`.
